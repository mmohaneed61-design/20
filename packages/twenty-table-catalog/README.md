# نظام الجدول المتقدم — 800 خاصية احترافية

> **Advanced Table System — 800 Professional Features Catalog (UI/UX)**
> حزمة ضمن نظام **Twenty** — صفحة ويب كاملة بالعربية (RTL) تعرض فهرس 800 خاصية احترافية لأنظمة الجداول، منظم في 14 مجموعة، وتطبق فعلياً أبرز خصائصه في عرضها.

## 🚀 التشغيل

الحزمة **صفر تبعيات** — لا تحتاج `yarn install` ولا أي بناء:

```bash
# من مجلد الحزمة
cd packages/twenty-table-catalog

# أي خادم ثابت (Python موجود على أغلب الأنظمة)
python3 -m http.server 3000 --bind 0.0.0.0

# أو عبر Nx من جذر المستودع
yarn nx serve twenty-table-catalog
```

ثم افتح: **http://localhost:3000**

## ✨ ما الذي تفعله الصفحة؟

الصفحة ليست مجرد جدول عرض — هي تطبيق UI/UX حي يطبق خصائص من الفهرس نفسه:

| المجال | ما تطبقه الصفحة |
|---|---|
| 🔍 الفلترة والتصفية (101-160) | بحث فوري أثناء الكتابة مع إبراز النتائج (139) |
| 🔃 الترتيب والفرز (161-200) | ترتيب بالنقر على رؤوس الأعمدة مع مؤشر الاتجاه (174/175) |
| 📋 الصفوف (51-100) | ترقيم الصفحات (98)، عرض عدد الصفوف (99)، ألوان متناوبة (75)، تمييز عند التمرير (76) |
| ⌨️ لوحة المفاتيح (281-340) | اختصار `/` للبحث و`Escape` للمسح |
| 🎨 التنسيق والعرض (401-480) | ثيم فاتح/داكن (466/467)، كثافة مريحة/مضغوطة (463/464)، رأس ثابت (452)، RTL (460) |
| 📤 التصدير (481-540) | تصدير CSV مع BOM لـ Excel (482) وJSON (484) للنتائج المفلترة فقط (495) |
| ️ الطباعة (306) | زر طباعة يعرض كل النتائج المفلترة في المستند المطبوع |
| ♿ إمكانية الوصول (711-750) | ARIA roles وlabels، aria-sort، aria-live، تركيز مرئي، دعم قارئات الشاشة |
| ⚙️ التخصيص (751-800) | حفظ الثيم والكثافة وحجم الصفحة في Local Storage (761) |

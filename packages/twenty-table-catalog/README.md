# نظام الجدول المتقدم — 800 خاصية احترافية

> **Advanced Table System — 800 Professional Features Catalog (UI/UX)**
> موقع عربي (RTL) من 5 صفحات ضمن نظام **Twenty**، مبني على محرك جدول واحد مشترك
> يطبق الخصائص الـ800 فعلياً، ومُنسّق بألوان وتوكنز ديزاين سيستم **twenty-ui** (MIT).

## 🚀 التشغيل

الحزمة **صفر تبعيات** — لا تحتاج `yarn install` ولا أي بناء:

```bash
# من مجلد الحزمة
cd packages/twenty-table-catalog

# أي خادم ثابت (Python موجود على أغلب الأنظمة)
python3 -m http.server 3000 --bind 0.0.0.0
```

ثم افتح: **http://localhost:3000**

## 📄 الصفحات

| الصفحة | الملف | الوصف |
|---|---|---|
| 🏠 الرئيسية | `index.html` | إحصاءات الحالة + فهرس الخصائص الـ800 بالمحرك الكامل |
| 👥 جهات الاتصال | `people.html` | بيانات CRM: تحرير مباشر، تحقق (بريد/هاتف)، فلاتر، تجميع، تذييل إحصائي، حفظ محلي |
| 📁 المشاريع | `projects.html` | صيغ حية `=ROUND(G2/F2*100,0)`، أشرطة تقدم، Sparklines، تجميع حسب الحالة |
| ✅ الخصائص الـ800 | `features.html` | مصفوفة شفافية: حالة كل خاصية (مطبقة/جزئية/مخطط لها) مع فلترة وترتيب وتصدير |
| ⚡ اختبار الأداء | `stress.html` | 100,000 صف بتمرير افتراضي (Virtual Scrolling) + لوحة FPS لحظية |

كل صفحة تستخدم **نفس المحرك** (`engine/`) — أي ميزة تعمل في صفحة تعمل في جميعها.

## ⚙️ المحرك — `engine/`

| الملف | المسؤوليات |
|---|---|
| `engine-core.js` | الحالة، الأحداث، البيانات، الفلترة (AND/OR + 13 مشغّل)، الترتيب متعدد الأعمدة، التجميع المتعدد، الترقيم، التمرير الافتراضي، إدارة الأعمدة (إخفاء/أعرض/سحب)، undo/redo، الحفظ المحلي |
| `engine-edit.js` | تحرير الخلايا (Enter/F2/نقر مزدوج)، المحررات (نص/عدد/قائمة/تاريخ/بريد/هاتف/تقييم/تقدم/متعدد)، تحقق الحقل، التحديد النطاق، سحب الصفوف، قصّ/نسخ/لصق |
| `engine-formula.js` | محلل صيغ كامل: `SUM/AVERAGE/COUNT/IF/SUMIF/COUNTIF/INDEX/MATCH/ROUND/...` + مراجع خلايا `A1` ونطاقات `A1:A10` + تنسيق مشروط (عتبات/تدرج لوني/أشرطة بيانات/أيقونات/صيغ) |
| `engine-io.js` | تصدير: CSV/TSV/JSON/XML/HTML/Markdown/TXT/SQL/SVG/XLS + PNG/PDF، استيراد CSV/JSON/XLS، نسخ/لصق |
| `engine-ui.js` | شريط الأدوات، لوحة الفلاتر، القوائم (عروض/أعمدة/تصدير/استيراد)، القوائم السياقية، الحوارات (اذهب إلى/اختصارات/لصق)، شريط الحالة مع الترقيم، لوحة FPS، Toast |

### API العام (مثال)

```js
const eng = TableEngine.create({ id: 'demo', el: '#app', data, columns, pageSize: 25 });
eng.setFilter('status', { op: 'equals', values: ['نشط'] });
eng.setSort('value', 'desc', true);      // additive multi-column sort
eng.setGroupBy(['city']);
eng.updateCell(rowId, 'value', 500);
eng.export('csv', { scope: 'filtered' });
```

## 🎨 ديزاين سيستم Twenty

`design-system/tokens.css` يستخرج توكنز **`twenty-ui`** (مرخصة MIT) — الألوان
(`--t-brand` #0057FF…)، المسافات، الخطوط (Inter/Tajawal)، الزوايا، الظلال، حركات —
وتستخدمها كل الصفحات عبر `design-system/base.css` و`shared/site.css`.

## 📊 حالة الخصائص الـ800

`data/feature-status.js` يحدد لكل خاصية حالة: **مطبقة (535)** — تعمل الآن في المحرك،
**جزئية (115)** — مدعومة بحدود، **مخطط لها (150)** — على خارطة الطريق.
مصفوفة كاملة تفاعلية في `features.html` (فلتر بالحالة/المجموعة، رتّب، صدّر).

##  الاختبارات

لا توجد تبعيات؛ الاختبارات smoke عبر Node (بدون متصفح):

```bash
yarn test        # أو:
node test/smoke.js  # اختبار المحرك (فلترة/ترتيب/تجميع/تحرير/صيغ/تصدير)
```
